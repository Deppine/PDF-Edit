# Lyra Desktop (.exe)

ห่อเว็บแอป Lyra ด้วย Electron ให้เปิดเป็นโปรแกรมบน Windows ทำงานในเครื่อง 100% ไม่ใช้อินเทอร์เน็ต
(ไฟล์ PDF ไม่ถูกส่งออกจากเครื่อง เหมือนเวอร์ชันเว็บ)

## วางโฟลเดอร์
โฟลเดอร์ `desktop-app` นี้ต้องอยู่ **ข้างใน** โฟลเดอร์ `PDF EDIT` (โฟลเดอร์ที่มี `index.html`)

```
PDF EDIT\
  index.html, script.js, style.css, theme-init.js, vendor\
  desktop-app\   <- โฟลเดอร์นี้
```

## สร้างไฟล์ .exe (ทำบนเครื่อง Windows)
1. ติดตั้ง Node.js LTS (https://nodejs.org) ครั้งเดียว
2. ดับเบิลคลิก `build-windows.bat` (ครั้งแรกต้องต่ออินเทอร์เน็ตเพื่อดาวน์โหลด Electron)
3. ได้โฟลเดอร์ `out\Lyra-win32-x64\` มี `Lyra.exe` อยู่ข้างใน

ตัวเลือกเสริม: `npm run dist` สร้างไฟล์ติดตั้ง (Setup) และไฟล์ portable ด้วย electron-builder
(บน Windows บางเครื่องต้องเปิด Developer Mode หรือรันแบบ Administrator ครั้งแรก)

## แจกให้พนักงานผ่านโฟลเดอร์กลาง
- คัดลอกทั้งโฟลเดอร์ `Lyra-win32-x64` ไปไว้ที่โฟลเดอร์กลาง (ต้องคัดลอกทั้งโฟลเดอร์ ไม่ใช่เฉพาะ Lyra.exe)
- เปิดจากโฟลเดอร์กลางได้เลย แต่เปิดครั้งแรกจะช้ากว่า แนะนำให้พนักงานคัดลอกไปไว้ในเครื่องตัวเอง
  (เช่น `C:\Lyra`) แล้วสร้าง Shortcut บนเดสก์ท็อป
- Windows อาจขึ้น "Windows protected your PC" เพราะไฟล์ยังไม่ได้เซ็นรับรอง: กด "More info" แล้ว "Run anyway"
  หรือให้ฝ่าย IT อนุญาตไฟล์ไว้ล่วงหน้า

## อัปเดตเวอร์ชัน
แก้เว็บแอปตามปกติ แล้วรัน `build-windows.bat` ใหม่ จากนั้นแทนที่โฟลเดอร์ใน โฟลเดอร์กลาง
(พนักงานต้องใช้โฟลเดอร์ใหม่ ระบบไม่อัปเดตตัวเอง)

## ทดสอบโดยไม่ต้องสร้าง .exe
`npm install` แล้ว `npm start`
