# PDF EDIT

เว็บแอปเครื่องมือแก้ไข PDF รวม 11 อย่าง ทำงานฝั่งเบราว์เซอร์ล้วนๆ (client-side) ไม่มี backend ไม่มีไฟล์ไหนถูกอัปโหลดไปที่ไหน และทำงานได้แบบ**ออฟไลน์ 100%** — ไลบรารีและฟอนต์ทั้งหมดเก็บไว้ในเครื่องแล้ว ไม่ต้องมีอินเทอร์เน็ตตอนใช้งาน

## เริ่มใช้งานแบบเร็วที่สุด

ดับเบิลคลิกไฟล์ **`OpenAll.bat`** ในโฟลเดอร์นี้ — จะเปิดเซิร์ฟเวอร์ที่ `http://localhost:8000` จากโฟลเดอร์นี้ให้อัตโนมัติ แล้วเปิดหน้าเว็บในเบราว์เซอร์ให้เลย (ต้องมี Python ติดตั้งในเครื่องแล้ว — ถ้ายังไม่มีดูวิธีติดตั้งด้านล่าง)

ใช้ `OpenAll.bat` แทนการดับเบิลคลิก `index.html` ตรง ๆ จะดีกว่า เพราะบางฟีเจอร์ (เช่นการอ่านข้อมูลจากภาพหน้าเอกสาร) ทำงานได้เสถียรกว่าเมื่อเปิดผ่านเซิร์ฟเวอร์ (`http://localhost:8000`) แทนการเปิดไฟล์ตรง ๆ (`file://`)

## เครื่องมือที่มี

- รวมไฟล์ PDF หลายไฟล์เป็นไฟล์เดียว
- แยก/ตัดหน้า (เลือกช่วงหน้า → รวมเป็น PDF เดียว หรือแยกเป็น ZIP คนละไฟล์)
- บีบอัดไฟล์ (แปลงแต่ละหน้าเป็นภาพคุณภาพที่ปรับได้)
- ใส่เลขหน้า (รองรับข้อความภาษาไทย)
- ใส่ลายน้ำ (รองรับข้อความภาษาไทย)
- ลงลายเซ็น (วางรูปลายเซ็นลงบนตำแหน่งที่ต้องการในแต่ละหน้า)
- ใส่รหัสผ่าน (เข้ารหัสไฟล์ PDF ด้วย RC4 หรือ AES-256 ตั้งรหัสผ่านเปิดไฟล์และ/หรือรหัสผ่านผู้ดูแลแยกกันได้)
- ปลดล็อกรหัสผ่าน (ปลดล็อกไฟล์ PDF ที่เข้ารหัสไว้แบบ RC4 หรือ AES-256 เมื่อทราบรหัสผ่าน — ไฟล์ที่เข้ารหัสแบบเก่ากว่านั้น (V4/AES-128) ยังไม่รองรับ)
- **แก้ไขเอกสาร (ทดสอบ)** — คลิกกล่องข้อความบนหน้าเอกสารเพื่อแก้ไขได้ทันที เลือกฟอนต์ได้หลายแบบ และดูดสีจากข้อความต้นฉบับให้อัตโนมัติ (เป็นการ "ปิดทับ" ข้อความเดิมด้วยกล่องสีแล้วเขียนทับที่ตำแหน่งเดิม ไม่ใช่การลบข้อมูลเดิมออกจากไฟล์จริง — ดูรายละเอียดในหน้าเว็บ)
- หมุนหน้า (หมุนทีละหน้าหรือเลือกหลายหน้าพร้อมกัน)
- รูปภาพ ↔ PDF (แปลงรูปภาพหลายไฟล์เป็น PDF เดียว หรือแปลงแต่ละหน้าของ PDF เป็นไฟล์รูปภาพ)

## โครงสร้างไฟล์

```
PDF EDIT/
├── OpenAll.bat                     ดับเบิลคลิกเพื่อเปิดเซิร์ฟเวอร์ที่ localhost:8000 และเปิดหน้าเว็บให้อัตโนมัติ
├── index.html                       โครงหน้าเว็บหลัก (11 เมนู)
├── style.css                        สไตล์ทั้งหมด
├── script.js                        โค้ดการทำงานของทุกเมนู
├── vendor/
│   ├── pdf-lib.min.js                   ไลบรารีสร้าง/แก้ไขไฟล์ PDF (เก็บไว้ในเครื่อง)
│   ├── pdf.min.js                       ไลบรารีอ่าน/แสดงผลไฟล์ PDF (เก็บไว้ในเครื่อง)
│   ├── pdf.worker.min.js                ตัวประมวลผลเบื้องหลังของ pdf.js (เก็บไว้ในเครื่อง)
│   ├── jszip.min.js                     ไลบรารีสร้างไฟล์ ZIP (เก็บไว้ในเครื่อง)
│   ├── pdf-encrypt.umd.js               ไลบรารีเข้ารหัส/ปลดรหัส PDF (เขียนขึ้นเอง)
│   ├── fontkit.umd.min.js               ไลบรารีสำหรับฝังฟอนต์กำหนดเอง (ใช้กับใส่เลขหน้า/ลายน้ำ/แก้ไขเอกสาร)
│   ├── thai-font-data.js                ฟอนต์ไทย (Loma, เข้ารหัส base64) ฝังไว้ในไฟล์
│   ├── quickedit-fonts-data.js          ฟอนต์ไทยอีก 5 แบบสำหรับเมนู "แก้ไขเอกสาร" (Loma, Garuda, Waree, Norasi, Purisa)
│   ├── google-fonts-local.css           ฟอนต์หน้าเว็บ (Prompt, Kanit) เก็บไว้ในเครื่อง แทนการโหลดจาก Google Fonts
│   └── fonts/                           ไฟล์ฟอนต์ .woff2 ของ Prompt และ Kanit (ใช้กับ google-fonts-local.css)
└── README.md
```

ไลบรารีและฟอนต์ทั้งหมดเก็บไว้ในโฟลเดอร์ `vendor/` แล้ว ไม่มีการโหลดอะไรจากอินเทอร์เน็ตอีกต่อไป — ใช้งานได้แม้ไม่มีอินเทอร์เน็ต

## การติดตั้ง Python (ทำครั้งเดียว สำหรับใช้ `OpenAll.bat`)

ติดตั้ง Python 3.9 ขึ้นไปจาก https://www.python.org/downloads/ (ติ๊ก "Add Python to PATH" ตอนติดตั้ง) — ใช้แค่เพื่อรันเซิร์ฟเวอร์ไฟล์พื้นฐาน (`python -m http.server`) ไม่ต้องติดตั้งไลบรารีเพิ่มเติมใดๆ

## วิธีรันแบบอื่น (ถ้าไม่อยากใช้ OpenAll.bat)

**เปิดไฟล์ตรงๆ** — ดับเบิลคลิก `index.html` ได้เลย ไม่ต้องติดตั้งอะไรเพิ่ม แต่บางฟีเจอร์ของเมนู "แก้ไขเอกสาร" อาจทำงานไม่เสถียรเท่าเปิดผ่านเซิร์ฟเวอร์

**ใช้ VS Code + Live Server** — เปิดโฟลเดอร์นี้ใน VS Code → ติดตั้งส่วนขยาย "Live Server" (โดย Ritwick Dey) → คลิกขวาที่ `index.html` → "Open with Live Server" (จะเปิดที่ `http://127.0.0.1:5500` แทน) — ถ้าใช้วิธีนี้ ให้แน่ใจว่า Live Server เปิดจากโฟลเดอร์ `PDF EDIT` นี้เท่านั้น ไม่ใช่โฟลเดอร์อื่นที่ไม่มี `style.css`/`script.js` อยู่ด้วย (ไม่งั้นหน้าเว็บจะโหลดไม่สมบูรณ์)

## ความปลอดภัย

หน้าเว็บมี Content-Security-Policy กำกับไว้ให้โหลดสคริปต์/สไตล์/ฟอนต์/รูปภาพจากในเครื่องเท่านั้น (`'self'`) ป้องกันความเสี่ยงจากโค้ดภายนอกที่ไม่พึงประสงค์ และข้อความ/ชื่อไฟล์ที่แสดงผลบนหน้าเว็บทั้งหมดผ่านการ escape ป้องกัน XSS แล้ว รหัสผ่านที่กรอกในเมนู "ใส่รหัสผ่าน" และ "ปลดล็อกรหัสผ่าน" จะถูกล้างออกจากช่องกรอกทันทีที่ประมวลผลสำเร็จ

## หมายเหตุ

- เครื่องมือ "บีบอัดไฟล์" เหมาะกับไฟล์ที่มีรูปภาพ/สแกนเยอะ ถ้าไฟล์เป็นข้อความล้วนขนาดเล็กอยู่แล้ว ผลลัพธ์อาจมีขนาดใหญ่ขึ้นแทน (ระบบจะแจ้งเตือนให้เห็นในหน้าเว็บ)
- ต้องการเครื่องมือเพิ่มเติม (สแกนเอกสาร, เซ็นดิจิทัลแบบมีใบรับรอง, กรอกฟอร์ม ฯลฯ) หรือจะให้ทำเป็นเว็บถาวรใช้งานจริงในบริษัท ต่อยอดจากโค้ดชุดนี้ได้เลย
